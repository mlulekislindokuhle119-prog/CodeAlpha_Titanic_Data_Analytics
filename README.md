# CodeAlpha_Titanic_Data_Analytics

Welcome to my repository for the **CodeAlpha Data Analytics Internship**. This project completes **Task 2 (Exploratory Data Analysis)** and **Task 3 (Data Visualization)** using the historic Titanic dataset[cite: 1].

---

## 📁 Repository Structure
* `titanic_analysis.py` - Python script containing the data loading, data cleaning, descriptive statistics, and visualization code.
* `README.md` - Project documentation and summary of findings.

---

## 🔍 Key Questions Addressed (EDA)
1. **Overall Survival Rate:** Analyzed the proportion of survivors versus casualties.
2. **Gender Impact:** Evaluated how passenger gender altered survival likelihood.
3. **Socioeconomic Status:** Checked how passenger class (`Pclass`) and ticket fare affected survival outcomes.
4. **Age Factor:** Compared the age distributions of survivors versus non-survivors.

---

## 📊 Key Findings & Insights
* **Overall Survival:** Approximately **38%** of passengers survived the disaster[cite: 1].
* **Gender Disparity:** Female passengers experienced a drastically higher survival rate (**~74%**) compared to male passengers (**~19%**)[cite: 1].
* **Class Advantage:** First-class passengers had priority access and higher survival outcomes relative to third-class passengers[cite: 1].
* **Age Factor:** Children showed higher relative survival rates across the demographics[cite: 1].
